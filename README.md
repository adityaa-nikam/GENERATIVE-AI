# Generative AI

A hands-on learning repository documenting my journey through Generative AI — from LLM fundamentals and prompt engineering to RAG systems, AI agents, tool calling, APIs, and multi-agent architectures.

This repository contains my implementations, experiments, notes, and project work developed while studying Generative AI concepts through structured learning resources.
