# Generative AI

Engineering implementations and experiments across modern Generative AI systems — covering LLM applications, retrieval pipelines, embeddings, vector search, tool use, and agentic workflows.

## Scope

- LLM APIs & chat models
- Prompt engineering & structured generation
- LangChain / LangChain Core
- Embedding pipelines
- Document ingestion & chunking
- Vector databases & semantic search
- Retrieval-Augmented Generation (RAG)
- Tool & function calling
- AI agents & agent workflows
- Multi-agent architectures

## Projects

| Project | Description |
